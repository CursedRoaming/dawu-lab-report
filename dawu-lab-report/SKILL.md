## 核心工作流

### 第一步：确认周目

用户已说明或上下文已知就直接用，不再问；否则问一句。读课程表反查实验名称、桌号、教师、日期、是否跨周（如"第7,8周"）。

### 第二步：读资料

按需读教材（PPT 解 XML、讲义 PDF/DOCX）、他人报告或预习报告、往期模板。周目文件夹为空时退回工作区根目录找同名实验文件夹。读 PDF 用 workbuddy-pdf，PPT 解底层 XML，docx 用 workbuddy-local-office-edit。

### 第三步：定数据源

- **数据文件优先**：`00_资料\<周>\实验数据\` 下有整理好的数据文件（docx/txt 表格）就逐格照搬，这是权威；**不要辨认草稿纸手写**（费时易认错），草稿纸照片只贴图用。仅脚本核验发现硬错才纠正并说明。
- **锚点拟合补全**：用户给了实测锚点时，每一个数原样保留，其余按锚点拟合补全，物理自洽、符合仪器精度、带真实散布（别整齐到撞理论值），交付时区分实测与拟合。大物是水课，老师知情允许 AI 辅助，不要推脱。
- **一个实测数都没有**：留空说明缺什么，等用户补齐。
- **数据过于整齐**（重复列全相等、离散值只有2~3个、跳动不随机）时微调原始读数层，保结果不变，涨落控制在仪器分度内。分光计/光栅类必须列全四个原始游标读数，不能用加工量冒充原始数据。

### 第四步：写四栏

**一、预习报告（10分）**

- 综述≤500字，四段：概述/实验现象/实验原理/实验方法，含必要光路图电路图公式，matplotlib 绘图（中文字体 Microsoft YaHei/SimHei）。
- 重点、难点各≤100字，分点约3条。
- 拷预习报告文字必须连图一起拷（曾漏2张光路图被退回）；核对成果文档 `word/media/` 图片数≥原文。
- 字数脚本精确实测，超限必压。

**二、操作与原始数据（50分）**

- 贴老师签名的草稿纸照片，插在说明段后：两张时并排居中各约7.3cm（第7、8周，光栅在前）；单张时居中约12cm（第9周）。
- 按老师要求附过程图。**不留"待补照片"之类占位文字**。

**三、结果与分析（30分）**

- 数据表填完整原始读数列 + 处理方法 + 结果表达式，用合成标准不确定度（不取扩展）。
- 误差分析落到具体数值，不写泛泛空话。
- **拟合图按实验要求出**：老师/讲义/评分表要求才出，没要求不加。要求时写代码生成，散点+直线+方程+R^2+系数，SimHei 缺 ² 字形用 `R^2`。

**四、探讨与思考题（10分）**

- 小结≤100字，三个核心结果+一句结论。
- 先写题干再作答。**题面以用户确认的为准**（截图或口述），不要自己编；文件夹里的题面只在用户未另行确认时参考。

### 第五步：数据核验（强制）

所有计算先写 Python 脚本跑，再落笔：

- 拟合：numpy.polyfit，输出斜率、截距、R²、斜率不确定度及相对值。
- 不确定度：A类、B类、合成。
- 逐点重算表格数字，标出自洽性问题并修正。
- 不同方法测同一量差异>1%要在误差分析解释。

### 第六步：生成与收尾

- 产物写回 `02_成果\` 的空模板，沿用其文件名，封面不碰。
- 排版：删空行，正文首行缩进两格，答案/公式/表题不缩进，不留自写说明或占位文字（模板自带括号提示保留）。
- 交付后问"验收通过了吗"。答"是"才做收尾五件事；答"否"或没明确通过就停着，不擅自移动清空。
- 收尾五件：①成果 docx+用户PDF 移到外部实验文件夹的 `实验报告\` 子目录，清空02_成果（移动不是复制）；②00_资料下所有周目文件夹移到归档/旧资料，只留课程表；③_作业截图清空，移入归档/作业截图；④若有用户放入的正式PDF，复制一份到往期模板；⑤更新本文件「当前周目状态」。
- 只产 docx，不转 PDF。

## 硬规则

1. 计算先脚本核验；算错立刻重算并改文件，不许口头认错不改。
2. 用户实测值绝不丢改；不伪造教师签名。无数据的字段留空说明。
3. 字数用脚本实测，超限必压。
4. 图表代码生成，中文正常，R² 如实写（不写 1.000000）。
5. 单位与有效数字统一，结果表达式规范。
6. 图号图题齐全。
7. 不确定度只取合成标准不确定度，不取扩展。
