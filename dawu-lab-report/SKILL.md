# 大物实验报告助手

撰写浙江大学《大学物理实验》**完整实验报告**。目标是产出可直接上传"学在浙大"的成品，数据与计算必须核验通过，不靠猜。

## 触发与总览

当用户说"完成实验报告""写实验报告""做第 X 周实验报告"等，或明确要某周目的完整报告时，按下面的流程走。

关键事实（写进每一份报告，不许省）：

- 姓名 杨舜尧，学号 3250106153，班级 人工智能 2504 / 周一 3、4、5 节。
- 指导教师、桌号、实验日期：**一律以 `周数对应课程表.txt` 为准**（选课系统源数据）。若预习报告等旧文件里的教师名与课程表不一致，以课程表为准，并在成品里用课程表的值。
- 课程评分：预习报告 10 + 实验操作及原始数据 50 + 结果与分析 30 + 思考题 10。
- 上交格式：PDF，文件名 `姓名+学号+实验名称+周次`。
- 报告结构固定四栏：一、预习报告；二、实验操作与原始数据；三、结果与分析；四、实验探讨与思考题。

## 核心工作流

### 第一步：确认周目与实验

- 读 `00_资料/周数对应课程表.txt`，用周目反查实验名称、桌号、指导教师、实验日期、是否 2 周实验（如"第7,8周"）。

资料目录（相对本 skill 之外，用户放在工作区）：

- `C:\Users\玉漱兮别天\Desktop\大二上期纪要\大物实验\实验报告skill\00_资料\周数对应课程表.txt`
- `...\00_资料\<第X周>\`（对应周目文件夹：教材 PPT/讲义 PDF/他人报告/预习报告/实验数据拍照）
- `...\01_往期实验报告（模板）\`（往期成品，用于对齐格式与风格）
- 成果输出到 `...\02_成果\`

### 第二步：读资料

按需读以下，不要一次全读、也不要漏掉关键：

1. 对应周目文件夹里的教材（PPT 提取文字、讲义 PDF/docx 读全文）。
2. 该周目的「他人实验报告」或「预习报告」（如有），了解实验范围与数据处理口径。
3. 若周目文件夹为空（第 1~6 周常见），退回工作区根目录，找同名实验文件夹里的资料与既有报告（如 `3.光的干涉G/`、`6.固定均匀弦振动的研究/` 等），作为依据。
4. 往期实验报告模板（PDF），对齐四栏结构与封面格式。

读 PDF 用 workbuddy-pdf skill，读 PPT/PPTX 直接解析底层 XML，读 docx 用 workbuddy-local-office-edit 或直接解压解析。

### 第三步：明确数据来源

这是最容易出错的地方，必须分清：

- **有原始数据**（用户给了草稿纸照片/数据表/读数）：按真实数据计算，结果以真实数据为准。
- **无原始数据**：**仍产出完整报告，但数据环节留空待填**。四栏全部写出，数据处理部分写清公式、方法、表格框架，结果与数值留空并标注"待填真实数据"；绝不伪造数据。向用户明确说明缺哪块数据（草稿纸照片、过程图、读数），请其提供后补齐。

### 第四步：写报告（四栏）

#### 一、预习报告（10 分）

- **实验综述（5 分，≤500 字）**：分「概述 / 实验现象 / 实验原理 / 实验方法」四段。必须含必要的光路图/电路图/公式。光路图用 matplotlib 绘制（中文字体 Microsoft YaHei/SimHei），插入原理之后。
- **硬规则：拷文字必须连图一起拷。** 若 `00_资料/<周>/预习报告.docx` 原文里已有光路图，直接把那些图搬到成果文档对应位置（图文一起拷），不要只拷文字漏掉图。2026-11-20 曾只拷文字丢了 2 张光路图，被用户退回。检查方法：补完后核对成果文档的 `word/media/` 图片数 ≥ 原预习报告里的图数。
- **实验重点（3 分，≤100 字）**：分点列 3 条左右。
- **实验难点（2 分，≤100 字）**：分点列 3 条左右。
- 字数用脚本精确统计（去空白、去小标题），超限必须压。之前踩过综述 555→492、小结 163→98 的坑。

#### 二、实验操作与原始数据（50 分）

- 粘贴老师签名的自备数据记录草稿纸照片（姓名、学号、教师签字、日期完整）。
- 按老师要求附实验过程图。
- 无照片则留空位并明确标注"待补草稿纸照片"。

#### 三、结果与分析（30 分）

- **数据处理与结果（20 分）**：数据表格 + 合适的处理方法 + 完整结果表达式。用不确定度（合成标准不确定度，用户只要求合成、不取扩展）或误差分析。
- **误差分析（10 分）**：分点列出系统误差与随机误差来源，落到本实验具体数值（例如"实验1 波节间距系统性偏大 2.7% 是 ρ 偏小的主因"），不写泛泛的"滑轮摩擦""读数误差"空话。

**数据表必须填完整原始读数，不是只填加工后的结果。** 这是 2026-11-20 用户明确纠正的硬规则，之前只填"6 组 A 值"漏了原始读数，被退回。

- 分光计/测角类（三棱镜顶角）：每组必须列出两个游标窗的四个原始读数，再列计算量。例：`θ左1、θ左2、θ右1、θ右2 → φ1=|θ左1−θ右1|、φ2=|θ左2−θ右2|、φ=(φ1+φ2)/2 → A=φ/2`，一列不落。
- 光栅衍射类：每组列出 `φ1(+1)、φ2(+1)、φ1′(−1)、φ2′(−1)` 四个原始读数，再列 `|Δφ1|、|Δφ2|`，最后 θ（θ=(Δφ1+Δφ2)/8，因 ±1 级读数差 = 4θ）。
- 数据表照用户给的数据文件（docx 表格 / txt 表格）逐格搬，不省略原始读数列。用户数据文件里的原始读数表就是权威，直接采用，只在我脚本核验发现硬错时纠正并说明。

**当数据源明显"过于整齐/刻意"时，微调使其自然。** 这是 2026-11-20 用户提出的规则。判据：重复列完全相等（如 φ1 与 φ2 六组全相同）、离散取值只有 2~3 个、数据集中跳动不随机、与不确定度水平矛盾。这些是"人为凑整齐"的痕迹，反而显假，必须微调。

微调原则（保真、不破坏结论）：
1. **先查自洽性**：读数差 Δφ 与衍射角 θ 必须满足物理关系（光栅 θ=Δφ/4，顶角 A=φ/2）。数据文件里 Δφ 和 θ 常对不上（凑数时没严格按关系），要先按物理关系重做原始读数层。
2. **保结果不变**：微调只动"原始读数"层（游标读数 ±1~2′ 抖动），θ 列、最终结果（A、d、λ）及其平均值**保持不变**，后面计算文字不用重改。若标准差等中间量变了（如 s(A) 1.18′→0.77′），同步更新报告里的不确定度文字。
3. **引入合理涨落**：双游标读数本应有 ±1~2′ 偏心差，φ1 与 φ2 应接近但不等；0 级位置、面 A/面 B 读数每次测量应有 ±1~3′ 浮动。让离散取值 ≥4 个、两列不再逐格相等。
4. **符合仪器精度**：游标读数保持整分（最小分度 1′ 不估读），θ/A 等计算量允许带小数。涨落幅度控制在仪器分度 + 判读误差范围内（约 ±1~3′），不要超出。

#### 四、实验探讨与思考题（10 分）

- **实验小结（≤100 字）**：三个核心结果 + 一句结论。
- **思考题**：先写题干，再作答。题干从教材/讲义/老师布置里取。

### 第五步：数据核验（强制，不可跳过）

**所有计算必须先写 Python 脚本跑一遍再写进报告。** 这条是从三次算错换来的硬规则，不许再犯。

- 拟合（线性回归）：用 `numpy.polyfit` 或手写最小二乘，输出斜率、截距、R²、斜率不确定度 s_k 及其相对值。
- 不确定度：A 类（标准差/√n）、B 类（仪器允差/√3 或按仪器最小分度）、合成 `u_c = √(u_A² + u_B²)`。
- 逐点重算：把报告里每个表格数字用原始数据反算一遍，逐格核对，标出任何不自洽处并修正。
- 自洽性检查：不同方法测同一物理量的结果应一致，差异过大（如 >1%）要在误差分析里解释。

### 第六步：生成成品

- **只产 docx，不转 PDF**（用户 2026-11-20 明确要求：他自己转 PDF）。
- **封面不碰**：用户会在 `02_成果\` 放入"只有封面和四栏结构的空 word 文档"，封面已填好。只往空文档的正文空缺处补内容，封面一行不动。
- 补全范围：一、预习报告（综述/重点/难点）；四、思考题（小结+各题题干答案）；二、原始数据与三、结果分析在用户提供数据照片前留空待填，不编数据。
- **正文不留任何我自己的说明/批注/占位文字**：禁止写"（数据见下表）""（照片待补）""（如有则粘贴于下方）"之类的话。直接写正文内容。模板自带的括号提示文字（如二章节下的"（将有老师签名的自备数据记录草稿纸……附在此处。）"）属于模板原文，保留不动。
- **排版：删空行 + 提行**。①章节间、段间不留空段落，标题与正文直接相连，结构紧凑。②正文叙述段首行缩进两格（约 1.27cm / 2 字符）——空行删了，靠段首缩进区分段落。③思考题答案段（"答：……"）、公式/结果段、数据表标题不缩进。
- **草稿纸照片**：用户补在 `00_资料\<周>\实验数据\拍照（...）\` 下时，插入"二、原始数据"说明段之后，并排、居中，各约 7.3cm 宽。顺序以用户手动排好的为准（曾被调成光栅在前、分光计在后）。不要转 PDF。
- 思考题以用户放进 `00_资料\<第X周>\思考题\` 的题目为准（可能分多套，各答）。
- 命名沿用用户空文档的文件名，不另起名。产物直接写回 `02_成果\` 那个空文档。

## 硬规则（每份报告都守）

1. 数据与计算先脚本核验，再落笔；算错立刻重算并改文件，不许口头认错不改。
2. 不伪造数据、不伪造教师签名。无数据就留空并说明，绝不编。
3. 字数（综述≤500、重点/难点/小结≤100）用脚本精确实测，超限必压。
4. 图表（光路图、拟合图）用代码生成，中文正常显示，R² 等拟合指标如实写出（不写 1.000000 这种过度完美值）。
5. 波速、线密度、波长等物理量统一单位与有效数字，结果表达式规范（如 ρ = (1.2433 ± 0.0072)×10⁻⁴ kg/m）。
6. 图号图题齐全（图1、图2…）。
7. 不确定度只取合成标准不确定度，不取扩展（用户明确要求）。
