# 大物实验报告助手（dawu-lab-report）

面向浙江大学《大学物理实验》课程报告撰写场景的 AI 技能。

一句话触发，自动读取课程表、教材讲义、实验数据与草稿纸照片，生成结构完整、数据经过核验的实验报告正文，产出可直接上传的规范命名 docx 文件。

## 功能

- **一句话触发**：说"完成第X周实验报告"即启动，无需逐步交代。
- **四栏全覆盖**：预习报告（10 分）、实验操作与原始数据（50 分）、结果与分析（30 分）、实验探讨与思考题（10 分）。
- **数据先核验后落笔**：所有计算用 Python 脚本逐格反算，不确定度按 A 类、B 类合成标准不确定度给出。
- **不伪造**：无原始数据时留空待填并明确说明缺什么，绝不编数据或签名。
- **配图自动化**：光路图、拟合图用 matplotlib 生成，中文正常显示，图号图题齐全。
- **持续迭代**：把反复踩过的坑固化为硬规则，随使用不断补强。

## 安装

将本目录放入 WorkBuddy 技能目录：

```
~/.workbuddy/skills/dawu-lab-report/
```

目录结构：

```
dawu-lab-report/
├── SKILL.md                    主定义：触发配置、六步工作流、四栏规范、硬规则
├── references/
│   └── report-spec.md          报告规范：封面、评分、字数、命名、数据口径
└── README.md                   本说明
```

## 使用

在 WorkBuddy 中直接说：

```
完成第7、8周实验报告
```

或：

```
我数据弄好了，以思考题文件夹里的为准，完成第7、8周实验报告
```

技能会按 `SKILL.md` 的六步流程执行：确认周目 → 读资料 → 明确数据来源 → 写四栏 → 数据核验 → 生成成品。

## 工作流

| 步骤 | 内容 |
|---|---|
| 1. 确认周目与实验 | 读课程表，反查实验名、桌号、教师、日期 |
| 2. 读资料 | 教材、讲义、他人报告、往期模板，按需取用 |
| 3. 明确数据来源 | 有数据按真实算；无数据留空待填，不伪造 |
| 4. 写报告四栏 | 按评分结构逐栏撰写，字数脚本实测 |
| 5. 数据核验 | Python 逐格反算，不自洽处修正 |
| 6. 生成成品 | 只产 docx，封面不碰，紧凑排版，规范命名 |

## 硬规则

1. 数据与计算先脚本核验，算错立刻改文件，不口头认错。
2. 不伪造数据、不伪造教师签名，无数据留空说明。
3. 字数脚本实测，超限必压。
4. 图表用代码生成，中文正常显示，拟合指标如实写。
5. 物理量统一单位与有效数字，结果表达式规范。
6. 图号图题齐全。
7. 不确定度只取合成标准不确定度，不取扩展。

## 产出示例

以第 7、8 周"分光计的调整和使用 + 光栅衍射"为例，成品为 9 页 docx，含 2 张光路图、2 张草稿纸照片、3 张完整原始数据表、8 道思考题解答。

核心结果：

```
A = (60.30 ± 0.01)°
d = (3347 ± 4) nm
λ = (435.1 ± 0.5) nm
```

按课程要求只产 docx，PDF 由学生自行转换。
